## Genus - Gaming Library App

**Mini Project | Android (Java) | iOS (Swift) | NodeJS (Express) | MySQL DB**

Genus is a gaming library app developed for both Android and iOS, allowing users to discover upcoming games, save their favorites, track played and wishlisted games, join a community forum, and chat with fellow gamers.

### Technologies & Tools Used

- **Mobile Development:**
  - **Android:** Java  
  - **iOS:** Swift
- **Backend Development:**
  - **Node.js:** Express framework
  - **Database:** MySQL
  - **Real-time Communication:** Socket.IO (bidirectional event-based communication)

### Project Description

Genus is a social application designed for Android and iOS platforms that serves as a video game library. It not only lets users explore upcoming and popular games but also enables communication between gamers through a forum and real-time chat. The app incorporates real-time, bidirectional, event-based communication using Socket.IO to enhance user interaction.
